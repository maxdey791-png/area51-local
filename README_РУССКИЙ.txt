ПРОВЕРКА ЛОКАЛЬНОГО ЗАПУСКА AREA 51

Это пробная оболочка запуска, а НЕ подтверждённая рабочая офлайн-версия.
Файлы взяты из вашего архива preloader.zip; index.html построен по сохранённой странице игры.

1. Откройте эту папку в Visual Studio Code.
2. Если установлено расширение Live Server, щёлкните правой кнопкой index.html → Open with Live Server.
3. Если расширения нет, установите Live Server (Ritwick Dey) в разделе Extensions.
4. Проверьте, появился ли игровой экран.
5. Если Loading Error / пустой экран: F12 → Console и Network → пришлите скриншоты ошибок.

Важно: двойным щелчком index.html запускать не стоит (file:// может мешать загрузке ресурсов).
Папка не содержит проверенных всех аудио, шрифтов и иных возможных ресурсов. Успешность запуска пока не установлена.
Использование исходного кода и графики зависит от прав правообладателя.
