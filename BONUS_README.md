# Виртуальные бонусы Area 51

Игра использует исходный `bundle.js`; `bonuses.js` подключает расширение через один вызов в модуле игровых классов. Бег, прыжки, препятствия, анимации и звуки остаются в оригинальном движке. Сборка не требуется.

Запуск из каталога репозитория: `python3 -m http.server 8000 --bind 127.0.0.1`.

F2 или кнопка «Бонусы» открывает настройки и приостанавливает игровой процесс. Esc/F2 закрывает панель. Настройки хранятся в localStorage этого браузера и адреса сайта. При недоступном хранилище панель показывает ошибку.

- Частота — вероятность одного бонуса на подходящей платформе (0–100%). Платформы с врагами исключаются.
- +100, +500, +1000, +5000 прибавляются к балансу; ×2, ×3, ×5, ×10 умножают текущий баланс. При нулевом балансе множитель даёт ноль.
- Отключённые множители не появляются. Допускается отключить все множители.
- Баланс начинается заново со стартового при каждом новом забеге. Сохранение настроек также сбрасывает баланс и пересоздаёт бонусы.
- Валюты Bs, PHP, THB, USD, RUB и собственный символ — только обозначения виртуальных игровых очков. Конвертации, ставок и выплат нет.
- Баланс ограничен максимальным безопасным целым JavaScript: 9 007 199 254 740 991.

Резервные копии исходных `bundle.js` и `index.html` сохранены вне Git-репозитория: `/workspace/area51-original-backup/`.

## Проверка

При работающем HTTP-сервере выполните `node tests/bonuses.cjs`. Тест использует установленный в облачной среде Playwright и `/usr/bin/chromium`; вне этой среды их нужно установить отдельно. Он проверяет все восемь типов бонусов, касание, однократность сбора, паузу F2, сохранение настроек после перезагрузки, свой символ и отсутствие бонусов при частоте 0%. Браузер теста использует отдельное временное хранилище.

Проверка синтаксиса: `node --check bonuses.js` и `node --check bundle.js`.
